# CASPRO LLC (Consulting and Services Pro LLC)

> Modern Enterprise Digital Engineering, Cloud Modernization, SAP GRC Governance & AI Consulting Website.

## 🚀 Overview
This repository contains the full production codebase for **[CASPRO LLC](https://www.casprollc.com)**, revamped with modern digital engineering aesthetics, high-density Bento grid layouts, interactive ROI estimators, and full service practices.

## 📁 Repository Structure
```
├── index.html             # First Page: "About Us" with "Why Choose Us", Framework, Values & Stats
├── services.html          # Second Page: "Services" (9-Practice Catalog & Case Highlights)
├── roi-calculator.html    # Third Page: "ROI Calculator" (Interactive Scope & Cost Estimator)
├── contact.html           # Fourth Page: "Contact Us" (RFP Submission Form & Direct Contacts)
├── about.html             # About Us (Synchronized alias)
├── calculator.html        # ROI Calculator (Redirect alias)
├── case-studies.html      # Enterprise Success Stories & Quantified Metrics
├── sitemap.xml            # Search Engine XML Sitemap
├── robots.txt             # Search Engine Crawler Directives
├── css/
│   └── style.css          # Master Responsive Design System & Dark/Light Themes
├── js/
│   └── main.js            # Interactive Engine (Theme toggle, ROI calculator, Modals)
└── assets/
    └── images/            # High-Resolution Cloud, AI & Security Assets
```

## 🛠️ Tech Stack
- **HTML5 & CSS3**: Modern Vanilla CSS with CSS Custom Properties, Glassmorphism, and responsive Bento grids.
- **JavaScript (ES6+)**: Zero runtime dependencies, high performance.
- **Typography**: Plus Jakarta Sans, Space Grotesk, JetBrains Mono (Google Fonts).
